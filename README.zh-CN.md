# DiPlay CN

本仓库基于上游 DiPlay `v0.2.12`。桌面名称为 **DiPlay CN**，包名为 `com.shihab.diplay.cn`，可与官方正式版并存。

为兼容的比亚迪安卓车机提供有线及无线 CarPlay，采用 DiAuto 风格界面。

> 这些项目专注于比亚迪汽车。它们可能在其他品牌上运行，但其他品牌不在支持范围内，也没有增加支持或修复其品牌特定兼容性问题的计划。

## CN 优化了什么

每一版改动都记录在 **[CN 优化日志](docs/CN_OPTIMIZATIONS.md)**：什么时间、改了什么、为什么改。当前基于官方 `v0.2.12`。

- 自定义转向卡 CN 增强版：大小 30%–95%、透明度 20%–100% 滑块；昼夜玻璃跟随车机；卡片下方行程信息条（到达 · 时长 · 里程）；无线切换掉线不清卡。
- 应用内更新（`0.2.10-cn.8` 起）：关于 → 检查更新，直接下载安装下一版，覆盖升级、设置保留。四通道：Gitee（默认）/ GitHub / gh-proxy.com / ghproxy.net。
- 开机自启 · ADB 修复：部分固件拦截开机广播时，一键把 DiPlay 加入后台白名单。
- CarPlay 期间延时暂停车机蓝牙（可选，5/10/15/30 秒）：来电只走 CarPlay，配对不受影响。
- 仪表盘地图新增「更小」档（125% 码流）：内容更多更精细。
- 车机语言不支持时默认简体中文；AirPlay 已连接后跳过无线切换看门狗，避免误重连。
- 自 `0.2.10-cn.4` 起固定签名密钥，新版本直接覆盖安装、设置保留。

0.2.11 为公开预览版，未经 Apple 认证。请安装在车机上，而非 iPhone。无需越狱、转接盒或认证服务器。无线连接支持车载热点或 Wi-Fi Direct（后者需要 Android 10 或更高版本）。

认证使用从公开固件中提取的实验性配件身份，无法保证未来持续可用。部分车机仍可能卡顿或无法应用图标大小设置。应用界面支持英语、简体中文、阿拉伯语、俄语、西班牙语和乌克兰语。源代码、构建说明及许可证随版本提供。

## 仪表显示「简易模式」怎么办

仪表进入简易模式是比亚迪仪表的自我保护（渲染或通信异常时降级）。若在使用 DiPlay 后出现：
1. DiPlay → 设置 → BYD 导航：关闭「仪表盘歌曲」「CarPlay 地图上仪表盘」，以及顶部总开关「HUD 和仪表盘导航」；
2. 重启车机，或在仪表主题里切换一次主题；
3. 恢复正常后再按需逐项打开，先开地图、最后才尝试歌曲。
